## 六、一页结论

**能给出什么**：一个**下限**与一个**单向的正面结论**。`peak_interval = [peak_allocated.lo, 不可计算]`，`oom_verdict ∈ {true, undetermined}`。`true` 的判据 `peak.lo > C_eff.hi` 两个操作数都有生产者。`undetermined` 时附一张平表（`absence` / `roots` / 可测否）+ 两个数（`blocking_set_size` / `unprovable_ratio`）。

**不能给出什么**：任何上界，因而"装得下"不在射程内——**这是定义不是缺口**。也**不能反驳任何人"这份配置会 OOM"的预测**：本工具只能独立地也说 `true`，或说"我不知道"。

**判据 1（可证伪）：成立。** 唯一的正面结论是 `true`，与它矛盾的观测是一次成功运行，证据完全落在 `P-oracle` 内。

**判据 5（代价单调）：在头号输出上成立，但"刚刚好"。** 危险方向已唯一化为"抬高 `peak.lo`"，四道防线各有落点（`inf_witness` 关系断言 · 测量/声明二分 · 条件三 · §0.1 反证）。**两个 θ 共用分母 `base = peak.lo`** ⇒ 抬高它一次买两样，已逐条写明已堵与未堵的入口。
